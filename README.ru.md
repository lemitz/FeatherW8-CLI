<h1 align="center">FeatherW8</h1>

<p align="center">
  Лёгкий самостоятельный аудиоплеер для Windows 10/11, который живёт в терминале.<br>
  Играет <code>MP3</code>, <code>WAV</code>, <code>Ogg Vorbis</code> и <code>Opus</code> bit-perfect через ASIO или WASAPI Exclusive. Без библиотеки, без телеметрии, без лишнего.

FeatherW8 делает одну вещь: берёт файлы или папки, которые ты ему дал, и играет их по порядку настолько честно, насколько позволяет железо. Здесь нет библиотеки, плейлистов и редактора тегов — только очередь, прогресс-бар и несколько клавиш. Плеер делался под настольный ЦАП FiiO K11, поэтому при наличии драйвера FiiO ASIO он выбирает его, а для любого другого USB DAC использует WASAPI Exclusive. В обоих случаях декодированный звук доходит до устройства нетронутым: без программного ресемплинга, без программной громкости, без микшера. Если строгий вывод для трека невозможен, плеер прямо об этом говорит и спрашивает разрешения, прежде чем опуститься до общего микшера Windows, — молча он этого не делает никогда.

Весь интерфейс целиком:

```
FeatherW8 0.2  |  MP3 · WAV · Ogg Vorbis · Opus
Трек 3/12: 03 - Blue in Green.opus
[=========================>-------------------------------------] 02:14 / 05:37
Статус: играет   Повтор: выкл.
Вывод: WASAPI Exclusive — Динамики (FiiO K11)
↑/↓ трек   ←/→ ±5 с (Shift ±30 с)   Space пауза   C повтор   Q/Esc выход
```

## Возможности

**Воспроизведение**
- MP3, WAV, Ogg Vorbis и Opus-in-Ogg, моно и стерео. Содержимое `.ogg` определяется по заголовку, так что Opus внутри `.ogg` играет так же, как `.opus`
- Принимает любую смесь файлов и папок — из командной строки, из контекстного меню Проводника или перетаскиванием на launcher
- Папки сканируются на один уровень вглубь и сортируются по имени файла; файлы, переданные явно, сохраняют свой порядок
- Перемотка на 5 или 30 секунд, пауза / продолжение, повтор выкл. → трек → очередь
- Прогресс-бар на всю ширину окна с прошедшим / общим временем, перерисовывается каждые 80 мс
- Интерфейс на русском, если язык интерфейса Windows русский, иначе на английском (в настройках можно задать принудительно)

**Bit-perfect-вывод**
- Режим `auto` сначала пробует драйвер FiiO ASIO, затем WASAPI Exclusive — на устройстве FiiO, иначе на единственном USB/DAC-устройстве, иначе на устройстве Windows по умолчанию
- WASAPI Exclusive открывается в raw-режиме с event-синхронизацией, приоритетом MMCSS «Pro Audio» и буфером 120 мс — мимо микшера Windows, APO-«улучшений» и любой программной громкости
- Сам FeatherW8 к сэмплам не прикасается: ни ресемплинга, ни громкости, ни DSP. Устройство должно принять частоту и формат трека как есть — плеер ничего не конвертирует за твоей спиной
- Если строгий вывод не запустился — неподдерживаемая частота, нет драйвера, устройство занято, ЦАП выдернули посреди трека — воспроизведение останавливается, и плеер спрашивает: `Enter` — продолжить через WASAPI Shared с того же места (с явной пометкой **НЕ bit-perfect**), `N` — пропустить трек, `Q` — выйти
- Активный путь вывода всегда виден на экране: `Вывод: ASIO — …`, `WASAPI Exclusive — …` или `WASAPI Shared — … — НЕ bit-perfect`

**Всё остальное**
- Один исполняемый файл и один текстовый файл настроек рядом с ним; portable-версия и установленная ведут себя одинаково
- Необязательное контекстное меню Проводника — «Проиграть в FeatherW8» для `.mp3` / `.wav` / `.ogg` / `.opus` и «Открыть папку в FeatherW8» для папок — только для текущего пользователя, без прав администратора и без смены приложений по умолчанию
- `--help`, осмысленные коды выхода (`0` — ок, `1` — ошибка воспроизведения, `2` — неверный вызов или нечего играть), переменные окружения в путях раскрываются
- Без телеметрии, без доступа в сеть, без фоновых служб; сам плеер ничего не пишет ни на диск, ни в реестр (единственные записи в реестре — необязательные ключи контекстного меню в `HKCU`)

## Клавиши

| Действие | Клавиши |
|---|---|
| Предыдущий / следующий трек | `↑` / `↓` |
| Назад / вперёд на 5 с | `←` / `→` |
| Назад / вперёд на 30 с | `Shift+←` / `Shift+→` |
| Пауза / продолжить | `Space` |
| Переключить повтор: выкл. → трек → очередь | `C` |
| Выход | `Q` или `Esc` |

Когда строгий вывод недоступен и плеер спрашивает, что делать:

| Действие | Клавиши |
|---|---|
| Продолжить через WASAPI Shared (не bit-perfect) | `Enter` |
| Пропустить трек | `N` |
| Выход | `Q` или `Esc` |

`↑` на первом треке запускает его заново (или переходит к последнему, если повтор — *очередь*); `↓` на последнем треке останавливает воспроизведение с сообщением, если повтор не *очередь*. Если согласиться на Shared клавишей `Enter`, он останется включённым до конца очереди — чтобы вернуться в строгий режим, перезапусти плеер.

## Установка

Каждая сборка даёт три варианта (см. [Сборка архивов и установщика](#сборка-архивов-и-установщика)):

- **Установщик** — `FeatherW8-Setup-win-x64.exe` (Inno Setup). Ставится для текущего пользователя в `%LocalAppData%\Programs\FeatherW8`, права администратора не нужны, язык установки берётся из Windows (русский / английский), контекстное меню Проводника предлагается отдельной галочкой, твой `FeatherW8.properties` при обновлении не трогается.
- **Portable** — `FeatherW8-Portable-win-x64.zip`: самодостаточный единый `FeatherW8.exe`, которому не нужен .NET на машине, плюс файл настроек и скрипты для Проводника. Распакуй куда угодно, переноси когда угодно.
- **Portable, маленький** — `FeatherW8-Portable-small-requires-dotnet10-win-x64.zip`: та же папка без встроенного рантайма; нужен установленный [.NET 10 runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

Бери их на странице [Releases](https://github.com/lemitz/FeatherW8-CLI/releases) или собери сам. FeatherW8 нужна Windows 10/11 x64 и больше ничего. Для ASIO на FiiO K11 отдельно поставь драйвер FiiO USB DAC — в комплект он не входит, а без него плеер просто использует WASAPI Exclusive.

### Запуск

Открой файл или папку из Проводника (через контекстное меню или перетащив на `FeatherW8-Launcher.bat` в portable-папке) либо из терминала:

```
FeatherW8.exe "D:\Music\Some Album"
FeatherW8.exe intro.wav "D:\Music\Some Album" bonus.opus
FeatherW8.exe --help
```

FeatherW8 нужно интерактивное окно консоли (подойдёт и Windows Terminal, и классическая консоль); если ввод или вывод перенаправлены, плеер завершится с кодом 2.

### Контекстное меню Проводника (portable-версия)

- `Register-Integration.bat` добавляет «Проиграть в FeatherW8» для файлов MP3/WAV/Ogg/Opus и «Открыть папку в FeatherW8» для папок — для текущего пользователя. В Windows 11 пункты находятся в «Показать дополнительные параметры».
- `Unregister-Integration.bat` их убирает.
- Windows хранит абсолютный путь к EXE, поэтому после переноса папки запусти `Register-Integration.bat` ещё раз.
- Установщик делает то же самое своей необязательной галочкой и убирает пункты при удалении.

## Настройки

`FeatherW8.properties` лежит рядом с `FeatherW8.exe`; отредактируй и перезапусти плеер. Строки, начинающиеся с `#`, — комментарии, регистр ключей не важен, неизвестные значения трактуются как `auto`.

```properties
language=auto
audio.output=auto
```

| Ключ | Значение | Что делает |
|---|---|---|
| `language` | `auto` | русский на русской Windows, английский на любой другой |
| | `ru`, `en` | принудительный язык (переключателя внутри плеера нет) |
| `audio.output` | `auto` | FiiO ASIO → WASAPI Exclusive → вопрос перед Shared |
| | `asio` | любой установленный ASIO-драйвер, FiiO в приоритете; если ни один не завёлся — предложит Shared, но не Exclusive |
| | `wasapi-exclusive` | WASAPI Exclusive на устройстве вывода Windows по умолчанию (синоним: `exclusive`) |
| | `shared` | WASAPI Shared на устройстве по умолчанию — всегда помечается как не bit-perfect |

## Как выбирается путь вывода

```
audio.output = auto
 ├─ 1. ASIO-драйвер, в имени которого есть «FiiO» или «K11»                            → строгий
 ├─ 2. WASAPI Exclusive на: устройстве FiiO → единственном устройстве с «USB»/«DAC» в имени
 │                          → устройстве вывода Windows по умолчанию                     → строгий
 └─ 3. ничего не запустилось → остановка и вопрос: Shared (НЕ bit-perfect) / пропустить трек / выйти
```

- Строгий путь принимается, только если устройство поддерживает число каналов, частоту дискретизации и (для WASAPI) формат сэмплов трека как есть; иначе он считается неудавшимся, и пробуется следующий кандидат.
- Если строгая сессия умерла посреди трека (выдернули ЦАП, отвалился драйвер), появляется тот же вопрос, и `Enter` продолжает с того места, где всё остановилось.
- Если USB-устройств не от FiiO несколько, FeatherW8 не гадает и берёт устройство Windows по умолчанию — назначь свой ЦАП устройством вывода по умолчанию.
- `auto` смотрит только на ASIO-драйверы FiiO/K11. Чтобы использовать другой ASIO-драйвер, поставь `audio.output=asio`.

Что на самом деле доходит до ЦАПа:

| Формат | Декодер | Уходит в устройство |
|---|---|---|
| WAV | NAudio `WaveFileReader` | ровно то, что лежит в файле |
| MP3 | Windows Media Foundation | 16-бит PCM с частотой файла |
| Ogg Vorbis | NVorbis | 32-бит float с частотой файла |
| Opus | Concentus | 16-бит PCM, 48 кГц (родная частота Opus) |

ASIO и WASAPI Exclusive гарантируют, что между декодером и драйвером FeatherW8 ничего не добавляет — ни микшера, ни ресемплера, ни усиления. Что делает внутри себя конкретный драйвер или ЦАП, плеер контролировать не может, а сжатые форматы, разумеется, сначала декодируются в PCM: «bit-perfect» для них означает, что выход декодера доставляется без изменений. Не каждое устройство принимает 32-бит float в эксклюзивном режиме — если твоё не принимает, на файлах Vorbis появится вопрос про Shared.

## Разработка

Требования:

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- Windows 10/11 x64, чтобы реально запускать. Проект компилируется и на Linux/macOS (включён `EnableWindowsTargeting`) — удобно для CI, — но вне Windows плеер сразу завершается
- По желанию: [Inno Setup 6](https://jrsoftware.org/isinfo.php) для установщика, FiiO K11 (или любое ASIO-устройство) для проверки ASIO-пути

```bash
dotnet build src/FeatherW8/FeatherW8.csproj
dotnet run --project src/FeatherW8 -- "D:\Music\Some Album"
```

Запускай из настоящего окна консоли: в панели вывода IDE с перенаправленными потоками плеер завершится с кодом 2. `FeatherW8.properties` копируется рядом с бинарником при сборке и публикации.

## Сборка архивов и установщика

```powershell
.\scripts\publish.ps1            # оба portable-архива → dist\
iscc installer\FeatherW8.iss     # установщик → dist\FeatherW8-Setup-win-x64.exe
```

`publish.ps1` делает два прохода `dotnet publish` для `win-x64` — self-contained single-file и framework-dependent, — кладёт рядом с EXE `FeatherW8.properties`, скрипты для Проводника и `THIRD-PARTY-NOTICES.md` и упаковывает обе папки в `dist\`. Установщик забирает self-contained-сборку из `publish\win-x64`, так что сначала запусти скрипт.

Перед распространением сборки с поддержкой ASIO проверь условия распространения ASIO SDK — см. [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). Драйвер FiiO в комплект не включается никогда.

## Известные ограничения

- Только Windows 10/11 x64.
- Нет рекурсивного обхода папок, M3U/CUE, shuffle, чтения тегов (показывается имя файла) и регулятора громкости — последнее намеренно: программная громкость ломает bit-perfect. Крути ручку на ЦАПе.
- Перемотка в Opus заново декодирует поток с начала, поэтому в длинном файле она может занять заметное время. Opus — только моно/стерео.
- У декодера Vorbis (NVorbis) есть upstream-особенности при перемотке в самый конец файла и обратно в начало.
- MP3 декодирует Windows Media Foundation; на редакциях Windows «N» сначала поставь Media Feature Pack.
- Устройства не от FiiO распознаются по имени («USB», «DAC»); что происходит, когда их несколько, — см. выше.

## Структура проекта

```
FeatherW8.properties           настройки по умолчанию, копируются рядом с EXE при сборке и публикации
src/FeatherW8/
  Program.cs                   точка входа: аргументы, --help, настройка консоли, главный цикл 80 мс
  Core/
    PlayerController.cs        навигация по очереди, обработка клавиш, режимы повтора, вопрос про Shared
    PlaybackSession.cs         один трек = одна сессия: декодер + устройство вывода, перемотка, пауза
    AudioOutputFactory.cs      выбор ASIO / WASAPI Exclusive / Shared и подбор устройства
    TrackQueueBuilder.cs       файлы и папки из командной строки → отсортированная очередь
    AppSettings.cs             парсер FeatherW8.properties
    Texts.cs                   встроенный каталог сообщений на русском и английском
  Audio/
    AudioSourceFactory.cs      выбирает декодер по расширению, различает Opus и Vorbis внутри .ogg
    OggOpusWaveStream.cs       перематываемый поток Opus-in-Ogg → PCM поверх Concentus
    SynchronizedWaveStream.cs  сериализует чтение декодера и перемотку из UI-потока
  UI/
    TerminalUi.cs              рисует экран: шапка, трек, прогресс-бар, статус, подсказки
scripts/
  publish.ps1                  собирает оба portable-архива в dist/
  portable/                    launcher и скрипты контекстного меню, которые едут в каждой сборке
installer/FeatherW8.iss        скрипт Inno Setup 6 для установщика текущего пользователя
icons/                         иконка приложения (.ico, исходный PNG, логотип для README)
THIRD-PARTY-NOTICES.md         лицензии используемых пакетов и примечание про ASIO
```

Разделение намеренное: `UI` только читает состояние `PlayerController` и рисует его, `Audio` только отдаёт `WaveStream`, а поток воспроизведения внутри устройства вывода NAudio тянет данные из декодера через `SynchronizedWaveStream`, поэтому перемотка из UI-потока никогда не гоняется с декодером.
